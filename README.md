# 📚 Drona Books

An online bookstore web app with 10 categories and 60 engineering, computer science and MBA books.

🔗 **Live demo:** https://kunal02042006.github.io/drona-books/

## ✨ Features

- Animated landing page
- Browse books by category (Mechanical, Electrical, Computer, CSIT, MBA, AI & ML, Civil, Electronics, Chemical, Aerospace)
- Add to cart and remove from cart
- Demo login and guest mode (no backend)

## 🛠️ Tech Stack

HTML5, CSS3, JavaScript

## 🚀 Run Locally

1. Download or clone this repo
2. Open `index.html` in your browser
